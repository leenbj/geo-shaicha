# geo-shaicha · 中文域名（.网址）AI 可见度检测 Skill

给一张企业表，跑出「四家中文 AI 是否在回答里提到该企业的 `.网址`」的证据库：逐家提问、命中截图、引用来源溯源、结果回写表格，并输出命中清单与统计。

适用：中文域名（.网址）AI 可见度统计、GEO 案例收集、按媒体渠道拆分投放效果。

## 覆盖平台

| 平台 | 站点 | 说明 |
|---|---|---|
| 豆包 | doubao.com | 会把域名里的 `.` 渲染成 `。`，判定需兼容 |
| DeepSeek | chat.deepseek.com | 有联网搜索，引用面板可抓 |
| 千问 | qianwen.com | 引用面板不渲染 href，来源抓不到 |
| 元宝 | yuanbao.tencent.com | 对 `.网址` 命中率通常最高；引用需点开新标签页 |

四个平台都需要浏览器里已登录（脚本复用用户登录态）。

## 问法（固定，不得变更）

1. 先问 `<公司全称>的官网是什么？`
2. **只有该平台没命中**，才在同一会话补问 `<公司简称>的官网是什么？`

## 输出

- 表格新增列：`豆包 / DeepSeek / 千问 / 元宝 / 命中平台 / 截图 / 状态 / 引用来源 / 引用链接`
- 截图：`案例截图/<域名>/<平台>-<全称|简称>.png`，只截「本次提问 + 本次回答」的白色浮层
- 工作表：`命中清单`、`统计`

## 快速开始

```bash
pip install openpyxl

# 1. 预处理：校验列、补公司简称（已有简称不覆盖）
python3 scripts/prepare.py --xlsx 表.xlsx --sheet Sheet1

# 2. 建浏览器空间并登录四个平台（脚本会自动新开标签页）
#    见 SKILL.md「建浏览器空间」一节

# 3. 跑检测（断点续跑，中断后重跑同一条命令即可）
python3 scripts/run.py --xlsx 表.xlsx --space 3 --outdir 案例截图 \
    --platforms doubao,deepseek,qianwen,yuanbao

# 4. 清理误判并重建清单/统计
python3 scripts/cleanup.py --xlsx 表.xlsx
```

## 硬规则（摘要）

- 命中必须与本行域名**等值**，防 `春芳.网址` 被 `中国春芳.网址` 误判
- 截图用浮层克隆，不整页截、不用 clip
- 平台间 15–35 秒随机间隔，家与家之间 15–30 秒
- 每 10 家换一次会话，避免历史堆积
- 已完成行跳过，`--reset` 才重跑

## 已验证的结论（供参考）

- 同一家企业两次提问结果可能不同（AI 回答有随机性）
- 命中率与**渠道覆盖广度**强相关：1 个平台 0%、2 个 23.5%、3 个 57.1%
- AI 实际引用的自媒体来源以**搜狐号**为主，百家号/头条号在引用面板里几乎不出现
