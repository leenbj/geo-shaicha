# 四家站点的选择器、坑位与限速经验

> 站点前端会变。这里的类名是 2026-10 实测有效的版本，改版后用 `page.snapshot()` 重新探。

## 通用

- 都需要用户在 ego lite 里**先登录**，脚本不处理登录/验证码。
- 提问输入框两种形态都出现过：`textarea`（首页态）和 `[contenteditable="true"]`（会话态）。两个都试。
- 回答是流式的，用「文本连续 2 次相同」判定生成结束，别用固定 sleep。
- **限速**：平台间 15–35s，企业间 15–30s。跑 84 家约 3–4 小时，别调太快。

## 豆包（doubao.com）

| 项 | 值 |
|---|---|
| 回答容器 | `[class*="md-box-root"]`（取最后一个） |
| 新会话 | 按钮文本 `新对话` |
| 提问气泡 | 也会命中 `md-box-root`，所以「最后一个」通常是回答，「倒数第二」才是提问 |
| 引用入口 | 回答下方 `参考 N 篇资料`，点开后是链接列表 |
| 坑 | 会把域名里的 `.` 渲染成 `。`（`名力亚。网址`），正则必须含 `。` |

## DeepSeek（chat.deepseek.com）

| 项 | 值 |
|---|---|
| 回答容器 | `.ds-markdown`（取最后一个） |
| 新会话 | 按钮文本 `开启新对话` |
| 引用入口 | 回答里的 `搜索到 N 个网页` |
| 坑 | 侧栏历史项是 `[class*="c08e6e93"]`（hash 类名，会变），自动化删会话点不开，别硬啃 |

## 千问（qianwen.com）

| 项 | 值 |
|---|---|
| 回答容器 | `.qk-markdown` |
| 新会话 | 按钮文本 `新对话` |
| 输入 | 只有 `[contenteditable="true"]`，用 `insertText` 而不是 `fill` |
| 坑 | 侧栏行是 `[data-session-switch-target="normal"]`，行内按钮点开不是删除菜单 |

## 元宝（yuanbao.tencent.com）

| 项 | 值 |
|---|---|
| 回答容器 | `.hyc-content-md` |
| 回答文本 | `.hyc-common-markdown`，外层还有 `agent-chat__speech-*` 包裹 |
| 新会话 | 按钮文本 `新建对话` |
| 引用入口 | 回答左下 `数据引用源`；引用图标是 `[class*="ref-list__item"]`，点开会在新标签页打开原文 |
| 坑 | 引用图标本身没有文本和 href，**只能点击后从新标签页读 URL**；有些源点是企查查/天眼查的登录墙 |

## 截图（通用）

不要用 `clip` 或整页截图——同一会话里有多家企业的问答，会串。做法：

1. 找到「本次回答」元素和「本次提问」气泡
2. `cloneNode(true)` 克隆进一个 `position:fixed;inset:0;background:#fff` 的浮层
3. 浮层高度超视口时按 `scale = (vh-30)/h` 缩放
4. `page.screenshot({ path })` 截视口，然后移除浮层

## 判定

```js
const RE = /[A-Za-z0-9\u4e00-\u9fa5\u00b7-]{2,}[.．。·・]网址/g;
```

命中后归一成英文点，再用**等值**校验是否等于本行域名（防 `春芳.网址` 被 `中国春芳.网址` 误命中）。

## 引用来源的可抓性（实测）

| 平台 | 入口 | 能否抓到 URL |
|---|---|---|
| 豆包 | `参考 N 篇资料` | 能，点开后 `a[href^=http]` 新增 |
| DeepSeek | `搜索到 N 个网页` | 能 |
| 千问 | `N 篇来源` | **不能**：面板打开后不渲染 href，抓不到链接，只能留空 |
| 元宝 | `数据引用源` | 需点开后从新标签页读 URL |

结论：引用来源统计以豆包、DeepSeek 为准，千问只报“命中”不报“来源”。

## 元宝的空间约定

`SKILL.md` 要求元宝单独建空间（避免与前三家抢标签页），但 `run.py` 目前用同一 `--space` + `p4`。
两种都可行，**以单独空间为准**（更稳）；若要单空间，需确认 `p4` 已创建且已登录。
